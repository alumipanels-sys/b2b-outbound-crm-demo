# Contributing

Thanks for helping B2B Outbound OS improve.

## Bugs and feedback

- Open an issue with the exact error message and what you were doing.
- Include your OS and Python version (`python --version`).

## Code changes

- Fork the repository, create a branch, open a pull request.
- Keep changes focused and explain why they are needed.

## Maintained files

`services/gemini_service.py` is maintained by the project owner. Pull
requests touching that file are not accepted. Everything else is fair game.

## Security

Never commit `.env`, database files, logs or API keys.
